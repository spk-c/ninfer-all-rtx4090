RTX 4090 KNOWLEDGE BASE

128K and long-context RTX 4090 LLM inference

Interpret context ceilings, KV memory, TTFT and controlled long-context performance evidence.

Context is a budget

Count rendered input, media tokens and generated output. The configured per-sequence ceiling differs from available shared KV capacity. Prefix reuse differs from computing a full prompt. Start conservatively:

--max-context 32768 --kv-capacity auto --kv-dtype rk4v4

Increase context gradually and inspect allocation failures, retained state, replay and retrieval quality.

Controlled development observations

Candidate 859d76b7 versus v0.1.3: −0.88% at 32K, +1.85% at 64K and +3.07% at 128K decode throughput, two repetitions per arm. Later 176,128 and 196,608 context results remain limited development evidence. Earlier short-decode tests regressed.

Testing

Repeat interleaved runs using a fixed token corpus, distinguish cached and computed input, measure TTFT/prefill/decode separately and verify output and memory. Do not extrapolate to untested binaries or contexts.
