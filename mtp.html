RTX 4090 KNOWLEDGE BASE

Multi-token prediction (MTP) CUDA inference

Configure compatible MTP components in NInfer and compare memory and draft performance fairly.

Choose MTP

MTP uses a compatible model's proposal component to draft candidate tokens for verification. Restart the server and replace DFlash2 flags:

--spec mtp --draft-tokens 3

Use --spec none as a baseline. Adaptive draft width is model and build dependent.

MTP versus DFlash2

Draft paths, memory footprint and verification cost differ. Compare the same model and inputs, and record rejected drafts, throughput, memory and output equality. Huihui serving-log results measured DFlash2 rather than MTP, so no MTP advantage is established.
