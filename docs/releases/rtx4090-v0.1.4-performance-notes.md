## Controlled RTX 4090 performance qualification (2026-11-26)

The exact published v0.1.4 binary completed 143 measurements: 78 Engine runs and 65 API requests, including eight overlapping streaming pairs, with zero reported infrastructure errors. The model-specific K7 / native prefill 4096 / concurrent-prefill preset was separately smoke-tested on a real RTX 4090.

| Context | K5 decode | K7 decode |
|---:|---:|---:|
| 64K | 242.75 tok/s | 272.74 tok/s |
| 128K | 206.39 tok/s | 240.60 tok/s |
| 176,128 | 214.87 tok/s | 263.93 tok/s |

Fixed-corpus Engine tests, two repetitions per cell, RK4V4, N-gram disabled. Separate copy-heavy source rename requests averaged 568.1 tok/s with N-gram 15 versus 256.7 without; both arms had 4/6 exact outputs. Concurrent prefill reduced short-request TTFT from 21.28 to 1.16 seconds during overlapping long prefill; pair wall time was essentially unchanged.

These are workload-specific observations, not guaranteed rates, a general coding-quality result or an upstream/other-engine comparison. The release artifact and tag are unchanged.
