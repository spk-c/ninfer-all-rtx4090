# RTX 4090 v0.1.4: code-copy and concurrent prefill (2026-11-26)

Same published release and artifact as the [controlled report](rtx4090-v014-long-context-2026-11-26.md).
The long coding test uses public C++ source at commit a6b1138: three complete target files and
five reference files per prompt, about 21,400 prompt tokens and 2,560–2,710 output tokens.
The task is an exact identifier rename in the target file, not compiling or evaluating a
general coding agent. Two repetitions with N-gram 0 and 15, fixed K7 and native prefill 4096.

| Metric | N-gram 0 | N-gram 15 |
|---|---:|---:|
| Mean per-request decode tok/s | 256.68 | 568.08 |
| Mean wall time | 14.83 s | 9.16 s |
| Exact output after outer formatting normalization | 4/6 | 4/6 |

Decode improvement: 121.3%; wall time reduction: 38.2%.
Outputs were identical across N-gram settings and repetitions for each fixture.
One target file differed slightly from the expected rename in both settings
(similarity 0.999737); the four exact outputs per arm are not six exact outputs.
N-gram is particularly effective on copy-heavy refactors and must not be presented as
a general model-quality or 568 tok/s guarantee.

## Concurrent prefill

Eight overlapping request pairs, four servers in ABBA order, concurrency 2.
In each prefill scenario a short 4,096-token prompt arrives one second after a 64,512-token
prompt; each produces 512 tokens. The short request TTFT is **21.28 s off versus
1.16 s on** (18.4x faster). Total pair wall time is essentially
unchanged at about 23.1 seconds. The long request's TTFT increases from about 20.2 to 22.1 s.
All pairs confirmed offered overlap; matching output hashes across arms.
When a long prefill is introduced during a 4,096-token output stream, both modes show
approximately 1.17 s maximum inter-chunk pause. This flag does not remove decode stalls.
These are streamed HTTP chunk gaps, not per-token GPU latency.

The recommended opt-in preset uses K7, N-gram 15, prefill 4096, concurrent prefill,
176128 context, RK4V4, two lanes, 16 GiB host cache, built-in device profile.
See [raw numerical evidence](../../profiles/bench/rtx4090-v014-long-coding-20261126/).
