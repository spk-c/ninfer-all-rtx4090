RTX 4090 local AI FAQ

Answers about local 27B inference, GGUF, Windows binaries, DFlash2, MTP and API access.

Models and hardware

Can a 27B model run on RTX 4090?

Yes for compatible quantized artifacts and suitable memory; a named Huihui artifact passed release smoke testing. Models.

Can I load any GGUF?

No. Use native converted .ninfer containers.

Do I need the CUDA Toolkit?

Not for the portable Windows package; compatible driver and runtime are required. Source builds require the documented toolchain.

Performance and serving

Is 215.5 tok/s guaranteed?

No, this is P90 per-request decode from one logged configuration.

Can I use coding clients?

Use the local OpenAI-compatible API and actual served model ID. Client features vary. Setup.

Can I use a prerelease?

Yes if you accept the documented validation scope. Hosted build tests are not real-GPU validation.
