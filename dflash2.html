RTX 4090 KNOWLEDGE BASE

DFlash2 speculative decoding on RTX 4090

Configure compatible DFlash2 models, test draft widths and measure acceptance and performance.

Configure a compatible model

DFlash2 uses companion weights to propose tokens for target verification. The documented Huihui setup starts at five drafts.

--spec dflash2 --draft-tokens 5

Use --spec none for a baseline, or --spec mtp --draft-tokens 3 for compatible MTP. Select one backend at startup.

Benchmark the draft width

Compare 3, 5, 7 and 9 drafts where supported; hold model, prompts, cache format, batch and GPU conditions fixed. Alternate runs and report acceptance, target verification costs, TTFT, decode, memory and output equality.

--request-log-jsonl requests.jsonl

Median 146.6 tok/s and P90 215.5 tok/s were observed with the Huihui non-Swift artifact, not isolated DFlash2 uplift.
