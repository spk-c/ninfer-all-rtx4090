NInfer RTX 4090 CUDA troubleshooting

Diagnose Windows startup, model loading, VRAM and local API issues.

Runtime will not start

Extract all archive volumes, verify SHA-256, retain backend folders and check driver and Visual C++ runtime.

.\ninfer-serve.exe --version
.\ninfer-serve.exe --help
nvidia-smi
Archive guide

Model load or memory failure

Verify the artifact checksum and native container format. Confirm the selected drafter exists. Reduce context and concurrency, close other GPU applications and try plain decode without vision. Record the original error.

VRAM planning

API failures

Invoke-RestMethod http://127.0.0.1:8080/v1/models

Use the returned model ID, check port and process state, and keep localhost binding unless appropriate access controls exist.

Report a reproducible issue

Include release/commit, GPU, driver, artifact, flags, logs, expected and observed results. Remove secrets and personal prompts.
