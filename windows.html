GET STARTED

Run a local LLM on RTX 4090 with Windows

Install the portable NInfer-all RTX 4090 runtime and launch a compatible model without compiling CUDA locally.

Download latest stable package

1. Install the runtime

  1. Use a compatible NVIDIA driver and Microsoft Visual C++ 2022 runtime.
  2. Download all matching .7z.* volumes and the SHA-256 manifest from the release.
  3. Compare each archive volume against its manifest, then extract .7z.001 with 7-Zip.
  4. Keep the backend directories intact. CUDA Toolkit installation is not required for the portable package.
Get-FileHash .\*.7z.* -Algorithm SHA256

See the Windows release archive guide.

2. Download and launch a compatible model

Open PowerShell in the extracted archive. The bundled launchers can download a supported upstream artifact and start the server.

.\download-model.bat qwen38-27b
.\run.bat qwen38-27b

For the community Huihui IQ3_S artifact, install the Hugging Face CLI and download the exact native file:

py -m pip install -U huggingface_hub
hf download SPK1337/Huihui-Qwen3.8-27B-Uncensored-GSQ-RCO-IQ3S-Vision-DFlash2-MTP-NInfer Huihui-Qwen3.8-27B-GSQ-RCO-IQ3S-Vision-DFlash2.ninfer --local-dir .\models

Launch from the extracted directory using a conservative 32K starting context:

.\ninfer-serve.exe .\models\Huihui-Qwen3.8-27B-GSQ-RCO-IQ3S-Vision-DFlash2.ninfer `
  --model-id huihui-qwen3.8-27b `
  --host 127.0.0.1 --port 8080 `
  --max-context 32768 --kv-capacity auto `
  --kv-dtype rk4v4 --gdn-state-fp16 `
  --spec dflash2 --draft-tokens 5

Full model card, checksums and settings. Use MTP instead by selecting --spec mtp --draft-tokens 3, not together with DFlash2. Vision is separately enabled where supported.

3. Connect a local OpenAI-compatible client

Invoke-RestMethod http://127.0.0.1:8080/v1/models

$body = @{
  model = 'huihui-qwen3.8-27b'
  messages = @(@{role='user'; content='Hello!'})
  max_tokens = 128
} | ConvertTo-Json -Depth 5

Invoke-RestMethod -Method Post `
  -Uri http://127.0.0.1:8080/v1/chat/completions `
  -ContentType 'application/json' -Body $body

Use the model ID reported by the server. Keep the server on localhost unless you configure appropriate authentication and access controls.

Frequently asked questions

Will a 27B model fit in 24 GB?

A compatible quantized artifact can fit. KV cache, speculation, vision and concurrent requests also consume memory. Start with a conservative context and adjust based on real measurements.

Can I load any GGUF?

No. NInfer uses native converted .ninfer artifacts, including supported GGUF-derived formats. See conversion documentation.

Can I build the engine myself?

Yes. Install Visual Studio 2022 C++ Build Tools, CMake, Ninja, CUDA 13.4 and documented dependencies. Follow the RTX 4090 guide and Windows build instructions.

Launch Inkling 2 Mini

Requires v0.1.8 or later compatible runtime and the guarded experimental model. Run inside the extracted runtime directory. The optional download command requires the Hugging Face CLI.

Model card and manual download

hf download SPK1337/Inkling-2-Mini-Uncensored-GSQ-RCO-IQ3_S-NInfer-v3 Inkling-2-Mini-GSQ-RCO-IQ3S-Rank1-v1-EXPERIMENTAL.ninfer --local-dir .\models
.\ninfer-serve.exe .\models\Inkling-2-Mini-GSQ-RCO-IQ3S-Rank1-v1-EXPERIMENTAL.ninfer --model-id inkling2-rank1 --host 127.0.0.1 --port 8080 --max-context 8192 --max-concurrency 1 --kv-dtype rk8v4 --expert-residency device --vision --structured-output --spec dflash2 --draft-tokens 7 --draft-min-p 0.5 --ngram-draft-tokens 0

Start with 8192 context and one request. Alternative: --spec dspark --draft-tokens 3. Do not combine drafters. Increase context only after checking available VRAM. API: http://127.0.0.1:8080/v1.
