Upstream recipes

Use a compatible current source build, matching artifact and configuration file. Check component availability in the exact release.

ninfer-serve --config configs/bonsai2-27b-dflash2.ini
ninfer-serve --config configs/bonsai2-27b-mtp.ini
ninfer-serve --config configs/bonsai2.5-27b-mtp.ini

These are upstream examples, not independent smoke tests of every binary. Current recipes.

Ternary formats and context

Upstream documents PTQ1_0 and PQ2_0 variants with different memory and throughput tradeoffs. Smaller weights can leave more room for KV storage, but extended context depends on cache format, configuration and runtime allocations. A configured ceiling does not establish retrieval quality.

  • Upstream Bonsai 2.5 measurements
  • Memory planning
  • Context testing

Verification

Start conservatively, test short generation, then increase context and compare settings. Record the exact artifact and commit. No new standalone Bonsai speed claim is made here.
