Native SM89 CUDA on RTX 4090: kernel routing and qualification

Why an architecture-specific build is only the starting point — and how NInfer measures kernel and graph changes.

What native SM89 actually means

Ada Lovelace compute capability 8.9 is the target of the native Windows build. The CUDA 13.4 wrapper builds sm_89 rather than depending solely on sm_86 forward compatibility. That does not automatically make inference faster. Tensor format, matrix shape, kernel implementation, register pressure and memory access patterns determine the useful route.

Calibration and reproducible routing

ninfer-calibrate measures route candidates on the actual device and overrides only measured route keys. A controlled comparison freezes model bytes, quantization, driver, toolkit, KV format, context, sampling and GPU state. Alternate A/B order, separate warmups and retain raw results. The SM89 qualification matrix specifies 54 cases, not 54 measured wins.

CUDA graphs and long context

Graph replay can reduce host launch overhead; changing attention shapes and addresses require safe resource envelopes and fallbacks. Experimental bucket, flat-draft and startup-calibration paths remain opt-in. In a 512-token follow-up with two repetitions, candidate defaults versus v0.1.3 measured −0.88% at 32K, +1.85% at 64K and +3.07% at 128K. Earlier 128-token runs regressed. Neither demonstrates a universal speedup.

Correctness before speed

Greedy output divergence, cache errors, missing sensors and unqualified kernel routes must not be presented as improvements. Check token sequences, retrieval, stability and memory as well as tokens/s. Complete flat-graph migration and real-model long-context qualification remain development tasks.
