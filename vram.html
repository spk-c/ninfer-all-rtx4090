A file is not the memory budget

The Huihui non-Swift artifact is 13.99 GiB on disk. Resident allocations vary with formats and components. Do not subtract file size from 24 GB and assume the rest is available.

Inspect and tune

nvidia-smi --query-gpu=name,memory.total,memory.used,memory.free --format=csv

Start at 32K or lower; reduce context or concurrency if memory is insufficient. Compare rk4v4 and rk8v4 quality and speed; disable optional vision or speculation if needed. Host/disk placement is model-specific.
