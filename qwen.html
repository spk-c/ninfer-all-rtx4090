Qwen3.8 27B on RTX 4090

Run Qwen 27B IQ3_S on a 24 GB RTX 4090, choose a model variant and configure speculation.

Select the artifact

Non-Swift and Swift 1.5 are distinct community conversions with mixed quantization, vision and speculative components. Their benchmark workloads differ and cannot establish a model-to-model speedup.

Conservative 32K setup

Download the stable runtime and model using the Windows setup guide.

.\ninfer-serve.exe .\models\Huihui-Qwen3.8-27B-GSQ-RCO-IQ3S-Vision-DFlash2.ninfer `
 --host 127.0.0.1 --port 8080 --model-id huihui-qwen3.8-27b `
 --max-context 32768 --kv-capacity auto --kv-dtype rk4v4 `
 --gdn-state-fp16 --spec dflash2 --draft-tokens 5

Choose MTP instead with --spec mtp --draft-tokens 3 if compatible. Enable vision separately and retest memory.

What to measure

Record TTFT, prefill, decode, peak VRAM, output equivalence and failures. Keep prompts, build, GPU conditions and cache format fixed. A model file size is not a VRAM budget.
