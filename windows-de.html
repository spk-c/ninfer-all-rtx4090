INSTALLATION

Lokale LLMs auf der RTX 4090 unter Windows

Portable CUDA-Version installieren und ein kompatibles Modell ohne eigene CUDA-Kompilierung ausführen.

Stabile Version herunterladen

1. Runtime vorbereiten

  1. Kompatiblen NVIDIA-Treiber und Microsoft Visual C++ 2022 Runtime installieren.
  2. Alle zugehörigen .7z.*-Archivteile und die SHA-256-Liste laden.
  3. Prüfsummen vergleichen, anschließend .7z.001 mit 7-Zip entpacken. Backend-Ordner nicht verschieben.
Get-FileHash .\*.7z.* -Algorithm SHA256

Das portable Paket benötigt kein separat installiertes CUDA Toolkit. Archiv-Dokumentation (EN).

2. Modell laden und starten

.\download-model.bat qwen38-27b
.\run.bat qwen38-27b

Alternativ das konkrete Huihui-Modell herunterladen:

py -m pip install -U huggingface_hub
hf download SPK1337/Huihui-Qwen3.8-27B-Uncensored-GSQ-RCO-IQ3S-Vision-DFlash2-MTP-NInfer Huihui-Qwen3.8-27B-GSQ-RCO-IQ3S-Vision-DFlash2.ninfer --local-dir .\models
.\ninfer-serve.exe .\models\Huihui-Qwen3.8-27B-GSQ-RCO-IQ3S-Vision-DFlash2.ninfer `
  --model-id huihui-qwen3.8-27b `
  --host 127.0.0.1 --port 8080 `
  --max-context 32768 --kv-capacity auto `
  --kv-dtype rk4v4 --gdn-state-fp16 `
  --spec dflash2 --draft-tokens 5

32K ist ein konservativer Startwert. MTP alternativ über --spec mtp --draft-tokens 3 wählen; Vision separat aktivieren und Speicherbedarf prüfen.

Model Card und Prüfsummen

3. Lokale API testen

Invoke-RestMethod http://127.0.0.1:8080/v1/models

$body = @{
  model = 'huihui-qwen3.8-27b'
  messages = @(@{role='user'; content='Hallo!'})
  max_tokens = 128
} | ConvertTo-Json -Depth 5

Invoke-RestMethod -Method Post `
  -Uri http://127.0.0.1:8080/v1/chat/completions `
  -ContentType 'application/json' -Body $body

Die tatsächliche Modell-ID aus der API verwenden. Lokale Bindung beibehalten, solange keine geeigneten Zugriffskontrollen eingerichtet sind.

Der neue Installer prüft das stabile SM89-Archiv per SHA-256 und installiert in ein neues Versionsverzeichnis. Der optionale GUI-Launcher startet einen lokal ausgewählten Runtime- und Modellpfad.

Inkling 2 Mini starten

Benötigt mindestens v0.1.8 und das geschützte experimentelle Modell. Nach dem Entpacken der Runtime im selben Verzeichnis ausführen. Die Hugging Face CLI muss für den optionalen Downloadbefehl installiert sein.

Model Card und manueller Download

hf download SPK1337/Inkling-2-Mini-Uncensored-GSQ-RCO-IQ3_S-NInfer-v3 Inkling-2-Mini-GSQ-RCO-IQ3S-Rank1-v1-EXPERIMENTAL.ninfer --local-dir .\models
.\ninfer-serve.exe .\models\Inkling-2-Mini-GSQ-RCO-IQ3S-Rank1-v1-EXPERIMENTAL.ninfer --model-id inkling2-rank1 --host 127.0.0.1 --port 8080 --max-context 8192 --max-concurrency 1 --kv-dtype rk8v4 --expert-residency device --vision --structured-output --spec dflash2 --draft-tokens 7 --draft-min-p 0.5 --ngram-draft-tokens 0

Start bei 8192 Kontext, eine Anfrage. DSpark alternativ: --spec dspark --draft-tokens 3. Nicht beide Drafter gleichzeitig verwenden. Längere Kontexte erst nach Prüfung des verfügbaren VRAM. API: http://127.0.0.1:8080/v1.
